# Financial Digital Twin: Cursor entry points

The portable [AGENTS.md](../AGENTS.md) is the working contract for this governance
workspace. Read the nearest app/service contract for the files being changed;
[docs/agent-guide.md](../docs/agent-guide.md) holds detailed operational guidance.
No personal harness installation or global plugin configuration is required.

## Current workflow

Start with the task's product mode: synthetic Pages demo, connected development
workspace, or engineering service. The [product vision](../docs/product-vision.md)
and [quick start](../docs/quickstart.md) explain the distinction. Preserve the
review/evidence boundaries and test the touched path before claiming completion.

[repo-context.mdc](rules/repo-context.mdc) routes to these portable instructions.
The Compose and worktree rules remain scoped protections against conflicting
stacks and false-green verification. [site-contract.mdc](rules/site-contract.mdc)
applies only to an explicitly active corporate site program; historical handoffs
are not standing authorization for ordinary repository work.

## Retained commands

The commands in this directory support historical workflows when explicitly
requested. Their presence does not activate an archived runtime or authorize a
new evaluation, schedule, benchmark, or external action.

| Commands | Purpose |
| --- | --- |
| `/verify-phase2` | Scoped ingestion/alert smoke verification |
| `/worktree-agent`, `/parallel-parent`, `/dependency-waves` | Optional isolation/coordination helpers |
| `/best-of-n-worktrees` | Explicitly scoped comparison work |
| `/live-eval`, `/live-eval-phase2`, `/token-efficiency` | Requested mechanical/behavior/efficiency evaluation |
| `/harness-health`, `/harness-snapshot` | Historical owning-tool inspection when explicitly in scope |

Use current source and live command output instead of private transcript or
terminal archaeology. Keep evaluation answer material separate from a live task.
See [the detailed guide](../docs/agent-guide.md#phase-completion-and-evaluation-criteria)
for retained criteria and [contributing](../CONTRIBUTING.md) for normal development.
